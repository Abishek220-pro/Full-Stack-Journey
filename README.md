## 📖 About This Repository

This repository documents my complete Full Stack Development journey — from the fundamentals of how the web works, through modern frontend and backend engineering, all the way to AI Engineering.

It's structured as a **198-day sprint**, broken into 22 phases. Every phase starts from true fundamentals — no topic is assumed — before moving into advanced, production-level concepts. Every phase includes notes, hands-on exercises, and small projects that prove the concept was actually understood, not just read.

> *"Consistency builds mastery."*
> Progress here is tracked daily, one phase at a time — no shortcuts, no skipped fundamentals.

**Update note:** This roadmap was rebuilt from an original 180-day plan to 198 days — every phase now opens with a dedicated fundamentals day (or days) before going deep, so nothing is learned on shaky ground.

## 🎯 Principles I'm Following

1. **No copy-paste** — if I can't rebuild it from memory, I haven't learned it yet
2. **Fundamentals first, always** — every phase starts from "what/why," never skips to intermediate
3. **Daily consistency** — even a short session beats a skipped day
4. **Build over read** — every phase ends in something working, not just notes
5. **Document everything** — `notes.md` files are written for future-me, not just present-me
6. **Revisit weak spots** — a gap found later gets patched, not ignored
